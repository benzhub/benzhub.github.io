Linux 萬用字元教學：安全使用 *、?、[] 與大括號展開

2024/01/04 2026/11/12
linux

Shell 萬用字元讓你一次選出多個檔名。輸入 *.txt 時，Bash 會先找目前目錄符合的檔案，再把結果交給命令；它不是 ls 或 rm 自己的語法。對批次移動或刪除，先在測試目錄預覽展開結果，確認後才執行。

*、?、[] 分別會選到什麼？

以下以 Bash 為例。Zsh 的無匹配行為與 Bash 不同，因此需要先確認目前 shell；不同語系下的字元範圍也可能有差異。

模式意義範例
*.txt* 匹配零個以上字元a.txt、file10.txt
file?.txt? 匹配剛好一個字元file1.txt，不含 file10.txt
file[1-3].txt[] 從集合選一個字元file1.txt 到 file3.txt
file[!0-9].txtBash 中排除指定集合filea.txt，不含 file1.txt

一般 * 不會穿過 /，也不會預設選取以 . 開頭的隱藏檔。Bash 預設找不到匹配檔案時，可能把未展開的模式原樣傳給命令；Zsh 通常直接報錯。需要遞迴搜尋時，用 find 的 -name 模式，或明確啟用 Bash globstar。可對照 Bash 檔名展開文件。

在隔離目錄先預覽，再批次複製

mkdir -p wildcard-demo/backup
cd wildcard-demo
touch file1.txt file2.txt file10.txt note.log scratch.tmp
printf '<%s>\n' file?.txt

預期只印出 <file1.txt> 與 <file2.txt>。確認結果後再複製：

cp -- file?.txt backup/
printf '<%s>\n' backup/*

-- 告訴支援它的命令後面是參數以外的路徑，避免檔名以 - 開頭時被誤當選項；macOS/BSD 工具的選項支援需另行確認。檔名中有空白時，shell 展開仍會把每個檔名當作獨立參數，寫迴圈時應使用 "$file"：

for file in *.txt; do
  printf '將處理：%s\n' "$file"
done

要刪檔案時，先看清單再確認

不要在不熟悉的目錄直接執行 rm *.tmp。在前面的 wildcard-demo 目錄裡，先預覽匹配結果，確認只有 scratch.tmp，再用互動模式刪除：

printf '<%s>\n' ./*.tmp
rm -i -- ./*.tmp

範例只適用於有匹配檔案且 rm 支援 -- 的環境；無匹配時先停止操作。需要跨子目錄刪檔，先用 find . -type f -name '*.tmp' -print 查看；不要在初次嘗試時直接加 -delete。所有刪除操作都應先有可用備份。

大括號展開與正規表示式有何不同？

{a,b} 是產生字串的 brace expansion，不要求檔案已存在。例如 printf '%s\n' report.{csv,tsv} 即使沒有檔案也會輸出兩個名稱。*.txt 則搜尋現有檔名。find . -name '*.txt' 的引號防止 shell 先展開，讓 find 自行比對；grep -E '[0-9]+' 使用的是正規表示式，語義又不同。詳見 Bash 大括號展開與 Linux 常用指令。
