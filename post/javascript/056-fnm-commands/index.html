fnm 安裝與常用指令：管理 Node.js 版本

2026/04/18 2026/11/14
javascript NodeJS fnm nvm 版本管理

fnm 是跨平台的 Node.js 版本管理工具，可安裝多個版本，並依專案的 .node-version 或 .nvmrc 切換。若你已經使用 nvm，先確認現有專案版本檔，再決定是否需要更換工具。

fnm、nvm 與 Node.js 各做什麼？

Node.js 是執行環境；fnm 與 nvm 是管理 Node.js 安裝版本的工具。本文聚焦 fnm 的安裝、shell 整合與常用指令；nvm 常用指令 專門說明 nvm。兩者的語法有相似處，但不能假設每個旗標都相容。

舊版本文宣稱「快 40 倍」及固定啟動時間，沒有同一台機器、相同 shell 設定與重複量測資料，因此移除。fnm 以 Rust 實作，nvm 為 shell 程式；實際載入時間會隨作業系統、shell、外掛和版本而變。要比較自己的環境，應分別在相同設定下多次量測冷啟動與開新 shell 的時間，記錄版本、硬體與統計方法。

安裝 fnm

依 fnm 官方安裝說明 選擇平台。macOS 已使用 Homebrew 時可執行：

brew install fnm
fnm --version

Windows 可在 PowerShell 使用 winget install Schniz.fnm；Linux 可從官方發行頁選擇對應架構，或檢查官方安裝腳本後再執行。不要在未檢查內容時直接把網路下載結果送入 shell。安裝完成後先重新開啟終端機，再執行 fnm --version。本文沒有在所有平台親測安裝流程，請以官方 README 的當前步驟為準。

讓 shell 載入 fnm

安裝本體後，依使用的 shell 把對應一行放進設定檔：

# Zsh：~/.zshrc
eval "$(fnm env --use-on-cd --shell zsh)"

# Bash：~/.bashrc
eval "$(fnm env --use-on-cd --shell bash)"

Fish 的 ~/.config/fish/conf.d/fnm.fish 使用：

fnm env --use-on-cd --shell fish | source

PowerShell 的 profile 使用：

fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression

修改設定後開新終端機。--use-on-cd 會在切換目錄時讀取版本檔；若沒有設定這個選項，仍可手動執行 fnm use。

安裝、切換與確認版本

以下是在已完成 shell 設定的終端機中執行的指令。LTS 會隨時間改變，所以不把某個主版本寫死為「最新 LTS」。

fnm install --lts --use
node --version
fnm current
fnm list

要在專案固定版本，可在專案目錄建立 .node-version，例如執行 node --version > .node-version。將版本檔納入版本控制後，團隊成員進入目錄即可依設定切換；若本機沒有該版本，先執行 fnm install。也可使用既有 .nvmrc。fnm default <版本> 設定未指定專案版本時的預設版本，fnm uninstall <版本> 會移除本機指定版本，執行前先確認沒有其他專案使用它。

fnm 有指令，node 卻找不到？

先檢查 shell 設定檔是否正確執行 fnm env，再於新終端機執行 fnm current、node --version。在專案目錄若尚未安裝版本檔指定的 Node.js，先執行 fnm install。若電腦同時安裝 nvm 或系統版 Node.js，再檢查 command -v node（Windows PowerShell 用 Get-Command node），確認目前取到哪個執行檔。

本文列出的跨平台指令依官方文件核對；實際安裝與自動切換仍取決於本機 shell 設定。官方參考：fnm README、fnm 指令文件、自動切換設定。
